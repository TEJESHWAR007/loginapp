# Secure Login System - Frontend

React + Vite frontend for the Secure Login System with JWT authentication.

## Tech Stack
- React 19
- Vite
- React Router 7
- Axios
- Tailwind CSS / Modern CSS

## Setup & Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```
   The app will run on `http://localhost:5173` (or configured port).

## Configuration
Configure the backend API URL in `.env`:
```env
VITE_API_BASE_URL=http://localhost:8081/api
```
